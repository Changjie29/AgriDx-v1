# 农机故障诊断知识库（示例 · 拖拉机常见故障）
# 说明：本文件为系统提示词的一部分。可直接编辑/追加真实维修手册内容，
#       保存后重启后端即生效。每条知识应包含：现象、可能原因、排查/处理、注意事项。

## 一、发动机水温过高（开锅）
- 现象：水温表指针进入红区、散热器开锅、怠速不稳、动力下降。
- 可能原因：
  1. 冷却液不足或渗漏（水箱、水管、水泵密封）。
  2. 节温器打不开或开启温度过高。
  3. 散热器外表堵塞（麦秸、尘土）或内部水垢严重。
  4. 风扇皮带打滑/断裂，或风扇离合器失效。
  5. 水泵损坏（叶轮松脱、水封漏水）。
  6. 喷油提前角过晚、混合气过浓导致燃烧过热。
  7. 长时间高负荷作业、超负荷牵引。
- 处理步骤：
  1. 立即降低负荷、靠边停机，**切勿立即拧开水箱盖**（高温高压蒸汽会喷出伤人）。
  2. 怠速降温 5–10 分钟后再检查。
  3. 检查冷却液液位与渗漏点；不足时补充同型号防冻液。
  4. 清理散热器外表；检查皮带张紧度（按压下沉 10–15mm 为正常）。
  5. 仍偏高则检查节温器（82℃ 左右应开启）与水泵。
- 注意：水温过高后禁止立即加冷水骤冷缸体，以防开裂。

## 二、发动机启动困难 / 不能启动
- 现象：启动马达转但不着火，或根本不转。
- 可能原因：
  1. 蓄电池亏电、接线柱松动氧化。
  2. 燃油系统进空气、柴油滤芯堵塞、油箱开关未开。
  3. 预热塞（冷启动系统）损坏，低温环境尤为明显。
  4. 喷油器雾化不良、喷油压力不足。
  5. 气缸压缩压力不足（活塞环磨损、气门漏气）。
- 处理步骤：
  1. 先看蓄电池电量与接线；听启动马达声音判断。
  2. 排燃油系统空气（拧松喷油泵放气螺塞，泵油至无气泡）。
  3. 冬季先预热 2–3 次再启动。
  4. 仍难启动则送检喷油器与气缸压力。

## 三、动力不足 / 冒黑烟
- 现象：加速无力、排气管冒黑烟、油耗上升。
- 可能原因：
  1. 空滤芯堵塞，进气不足。
  2. 喷油泵/喷油器故障，雾化不良或供油过多。
  3. 喷油提前角失准。
  4. 增压中冷器（如有）漏气。
  5. 缸压不足。
- 处理：清洁或更换空滤；校喷油器与喷油泵；核对供油提前角。

## 四、液压系统故障
- 现象：提升无力、农具沉降、系统噪音/过热。
- 可能原因：液压油不足或牌号不对、滤芯堵塞、齿轮泵磨损、分配阀泄漏、油缸内泄。
- 处理：检查油位与油温（正常 40–80℃）；换液压油与滤芯；测系统压力（按机型铭牌，常见 16–20 MPa）。

## 五、电气系统故障
- 现象：充电指示灯常亮、喇叭弱、灯光暗。
- 可能原因：发电机皮带打滑、调节器损坏、发电机碳刷磨损、接线松动。
- 处理：检查皮带与接线；测发电机输出（怠速 13.5V 以上为正常）。

## 六、制动与转向
- 制动跑偏：两侧制动片磨损不均、轮胎气压不一致。
- 转向沉重：液压转向油不足、油泵磨损、前束失准。

## 七、保养周期（以 100 小时为基础单位，具体以机型手册为准）
- 每 50 小时：检查机油油位、冷却液、轮胎气压。
- 每 100 小时：更换机油及机油滤芯；检查空滤。
- 每 200 小时：更换柴油滤芯；清理散热器与空滤内芯。
- 每 500 小时：更换液压油（或按油质判断）；检查气门间隙。
- 每 1000 小时：检查喷油器、气缸压力；更换防冻液。

## 八、安全规范
- 维修前熄火、拉手刹、取下钥匙，液压农具落地。
- 高温高压部件（水箱、排气管、液压油管）冷却后再接触。
- 严禁在发动机运转时清理散热器或加注燃油。
