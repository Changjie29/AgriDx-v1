# 约翰迪尔 9R 系列拖拉机 诊断故障码（DTC）

> 来源：中国农业机械流通协会（CAMDA）《约翰迪尔9R系列拖拉机诊断故障码》，作者：北垦农机
> 原文：https://www.camda.cn/message/2017/31971.html
> 说明：本文件抽取了其中**驾驶员可自行处置**的常见故障码，按控制单元分组。完整表格请用 scripts/kb-fetch.mjs 抓取原文后合并。
> 免责：故障码仅供参考，涉及液压/传动/电控总成维修请联系当地服务商。
> 通用处置原则：很多故障码可通过"循环开关钥匙"或按 CommandCenter 页面提示操作后循环钥匙来复位的；若反复出现或报警成片，请联系经销商。

- ECU 000111.01 冷却液液位极低（功率受限）—— 添加冷却液并检查是否泄漏
- ECU 000111.07 冷却液液位电路故障 —— 液位监视器不起作用，人工验证冷却液液位
